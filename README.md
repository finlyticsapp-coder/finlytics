# Finlytics
Plataforma de análise de portfólio

## Descrição
Finlytics é uma plataforma de análise de portfólio que permite calcular retorno esperado, risco estimado e simulações de Monte Carlo para investimentos. O projeto utiliza HTML, JavaScript e gráficos interativos para fornecer visualizações claras e precisas.

## Tecnologias
- HTML5
- CSS3
- JavaScript (ES6)
- [Chart.js](https://www.chartjs.org/) para gráficos
- Deploy via [Vercel](https://vercel.com/)

## Funcionalidades
- Cálculo de retorno esperado e risco baseado em pesos, retornos e riscos dos ativos.
- Simulação de Monte Carlo para prever valor médio do portfólio em 10 anos.
- Visualização gráfica do portfólio em gráficos de pizza.
- Preparado para atualização e expansão com mais ativos e métricas.
